# Let's Walk · Пошли гулять

Приложение, где прогулка начинается с одной кнопки. Нажимаешь «Пошли гулять», указываешь место, время и настроение, и друзья видят твою прогулку онлайн и могут присоединиться.

Главная идея: убрать момент «ну не знаю, куда идти и с кем».

## Что умеет прототип

- **Карта на главном экране**: нажимаешь на карту и ставишь точку встречи (метку можно перетащить), адрес подставляется сам.
- **Значки прогулок на карте** с временем начала и числом участников. Красный значок означает, что прогулка идёт сейчас, жёлтый — твоя прогулка. По нажатию открывается карточка.
- **Только актуальное**: закончившиеся прогулки сами исчезают с карты и из списка.
- **Где я**: кнопка показывает твоё место на карте и расстояние до каждой прогулки.
- **Создать прогулку**: место встречи, день (на две недели вперёд), время, настроение (спокойно, активно, с кофе, к воде, с собакой, фото-прогулка) и короткая заметка.
- **Общая карта в реальном времени**: прогулки появляются у всех без перезагрузки, с пометками «через 20 минут» и «идёт сейчас».
- **Присоединиться** кнопкой «Я с вами». В карточке видно, кто зовёт и кто идёт.
- **Кто онлайн**: сколько людей сейчас открыли приложение.
- **Позвать друзей**: кнопка в карточке отправляет ссылку в любой мессенджер; по ссылке сразу открывается эта прогулка на карте (`…/Let-s-Walk/#w-<id>`).
- **Чат прогулки**: у каждой прогулки свой чат для автора и тех, кто идёт, с быстрыми фразами («Я на месте», «Опаздываю на 5 минут»). Посторонние его не видят.
- **Как приложение на телефоне**: иконка на экране «Домой», запуск без адресной строки, подсказка по установке (iPhone: «Поделиться» → «На экран Домой»; Android: кнопка «Установить»). Файлы: `manifest.webmanifest`, `sw.js`.
- **Безопасность**: пожаловаться на прогулку или сообщение (кнопка «⋯» в карточке, нажатие на сообщение в чате), скрыть человека (его прогулки и сообщения пропадают; вернуть можно в профиле). Прогулка, на которую пожаловались 3 разных человека, скрывается автоматически. Все жалобы — в Supabase → Table Editor → `reports`.
- **Вход и профиль**: регистрация по email и паролю, своё имя в профиле.
- **Задание прогулки**: маленький челлендж для каждой прогулки («найдите самую старую дверь»).
- **Изменить или отменить** свою прогулку: время, день, место (можно сдвинуть точку на карте), настроение, заметку. Об изменениях участникам автоматически пишется в чат прогулки.

## Как устроено

Приложение — один файл `index.html`, который открывается как сайт: https://mrbokovets-debug.github.io/Let-s-Walk/

| Часть | Чем сделано |
|---|---|
| Карта | Leaflet + OpenStreetMap, адреса через Nominatim |
| База данных, вход, онлайн | Supabase (Postgres, Auth, Realtime) |
| Схема базы и правила доступа | [`supabase/schema.sql`](supabase/schema.sql), [`supabase/02_chat.sql`](supabase/02_chat.sql), [`supabase/03_safety.sql`](supabase/03_safety.sql) |
| Хостинг | GitHub Pages |

- Смотреть прогулки может любой, у кого есть ссылка. Создавать прогулки и присоединяться можно после входа по email и паролю.
- Новые прогулки и участники появляются у всех сразу (Supabase Realtime). Вверху видно, сколько людей сейчас онлайн.
- Публичный ключ Supabase в коде — это нормально: данные защищают правила доступа (Row Level Security) в базе. Секретный ключ `service_role` в коде не хранится и не должен.

### Настройки Supabase для теста

- Authentication → Sign In / Providers → **Confirm email: выключено** (вход без писем). Перед запуском включить обратно и подключить свою почту (SMTP).
- Authentication → URL Configuration → Site URL: `https://mrbokovets-debug.github.io/Let-s-Walk/`

## Безопасность

Люди будут встречаться вживую, поэтому до публичного запуска обязательны: подтверждение профилей, жалобы и блокировка, встречи только в публичных местах и возможность поделиться маршрутом с близкими.
